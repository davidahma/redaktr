# Changelog

## 0.2.0 — community source preview

- Build and run the native macOS editor and Swift package from the public source. The community build includes scan, review, copy, and export without activation, a trial, or an in-app updater.
- Start with a synthetic support ticket, inspect the flattened output, and contribute a detector case using fictional data and independently identified regions.
- Protect existing output when saving or retrying batches. Clipboard replacement and undo check that the clipboard still contains the item Redaktr owns.
- Added generated email and QR images that exercise Vision, rendering, and inspection of preserved pixels.
- Users of the earlier direct-sale app can transfer local detection policies with the [migration guide](docs/product/migration.md). See the [README](README.md) for build and upgrade instructions.
